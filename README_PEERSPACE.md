# PeerSpace Laravel 13 — UI + Backend + Security Upgrade

Project code hasil integrasi dari arsip pengguna. Tidak menyertakan `artisan`, `composer.json`, `.env`, `vendor`, atau `node_modules`; gabungkan ke **Laravel asli**. Sebelum menyalin, **backup** dan cek perubahan file.

**BACA DULU:** `SECURITY_SETUP/README_SECURITY.md` untuk tahap pemasangan, tes, konfigurasi TURN, kebijakan production dan batas perlindungan.

Backend: Laravel HTTP signaling, database matchmaking, guest session, CSRF, per-route throttling, validasi SDP/ICE/chat, reported users. Frontend: dashboard, navbar/sidebar/footer, random video, screen share, chat. DILARANG menganggap ini production-ready hanya karena tampilan berjalan.
